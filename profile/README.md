# NodeNexus

Удалённое управление нодами и VPS-серверами.

[![GitHub](https://img.shields.io/badge/GitHub-NodeNexusDev-181717?style=flat&logo=github)](https://github.com/NodeNexusDev)

## О проекте

NodeNexus — это инструмент для централизованного управления серверной инфраструктурой. Позволяет работать с удалёнными нодами (VPS) из единого интерфейса.

## Репозитории

| Компонент | Описание |
|-----------|----------|
| [node_nexus_api](https://github.com/NodeNexusDev/node_nexus_api) | Backend API |
| [node_nexus_panel](https://github.com/NodeNexusDev/node_nexus_panel) | Веб-панель |
| [node_nexus_tui](https://github.com/NodeNexusDev/node_nexus_tui) | TUI-клиент |

## Статус

Проект в ранней стадии разработки.
